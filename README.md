## 📲 Installation

1. 📥 Download the latest **`SparkBox-vX.X.X.apk`** from the [Releases](https://github.com/devfahim00/SparkBox/releases/latest) page.
2. 🔓 Open the file and allow **Install from unknown sources** if Android asks.
3. 🚀 Install, open SparkBox and enjoy!

> **Requirements:** Android 7.0 (API 24) or higher.

## 🔄 Updates

SparkBox silently checks this repository's releases every time you open the app.
When a new version is available you'll get a popup, and the app downloads and installs it for you.

> ⚠️ Older versions can't play videos. Update to the latest release to keep watching.
